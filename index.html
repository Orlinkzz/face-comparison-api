Verifikasi wajah foto profil vs selfie dalam satu request

Face Comparison API adalah REST API open source (Python, Flask, face_recognition) untuk membandingkan dua foto wajah. Jalankan dengan Docker, kirim dua gambar, dan dapatkan hasil cocok, perlu verifikasi, atau tidak cocok beserta nilai distance-nya.

Coba sekarang Source code
Python 3.11 Flask face_recognition / dlib Docker + Gunicorn CORS

Coba langsung

Jalankan API Anda terlebih dahulu, lalu bandingkan foto profil dengan selfie. Gambar tidak dikirim ke mana pun selain URL yang Anda isi.

Tersimpan di browser Anda. Jika di belakang reverse proxy, sesuaikan path-nya, misalnya https://domain-anda/face-recognition/compare_faces.
Gambar contoh: samples/profile.jpg dan samples/selfie.jpg.

Cara membaca hasil

        
Setiap wajah diubah menjadi vektor 128 dimensi. Makin kecil jarak (distance) antar vektor, makin mirip wajahnya.

      

      

        

          
< 0.45
success
          
Wajah cocok. Aman diterima otomatis.

        

        

          
0.45 – 0.6
pending
          
Kemungkinan cocok, tapi sebaiknya diverifikasi manual.

        

        

          
≥ 0.6
error
          
Wajah tidak cocok. Distance null berarti wajah tidak terdeteksi.

        

      

    

  


  

    

      

        
Mulai dalam 1 menit

        
Clone repo, jalankan dengan Docker, lalu kirim request.

      

      

        
        
        
      

      

        
        
git clone https://github.com/orlinkzz/face-comparison-api.git
cd face-comparison-api
docker network create web
docker compose up -d --build

        
curl -X POST http://localhost:5000/compare_faces \
  -F "image1=@samples/profile.jpg" \
  -F "image2=@samples/selfie.jpg"

          Face Comparison API adalah REST API open source untuk verifikasi wajah
          (face verification): membandingkan foto profil dengan selfie dan menentukan apakah keduanya orang yang sama.
          Cocok untuk absensi selfie karyawan, verifikasi identitas (e-KYC) sederhana, validasi foto akun, atau sebagai
          backend face matching untuk aplikasi web dan mobile (Laravel, Node.js, Flutter, dan lainnya).
        

        

          English: an open-source, self-hosted face comparison / face verification REST API built with
          Python, Flask and face_recognition (dlib). Compare a profile photo with a selfie and get a match,
          pending or no-match result with the face distance. Docker-ready, MIT licensed.
        

      

    

  


  

    

      

        
Pertanyaan umum (FAQ)

      

      

        

          Bagaimana cara kerja perbandingan wajah?
          
Setiap wajah diubah menjadi vektor 128 dimensi (face encoding). API menghitung jarak (distance)
            antara kedua vektor: makin kecil jaraknya, makin mirip wajahnya. Di bawah 0.45 dianggap cocok,
            0.45–0.6 perlu verifikasi manual, dan 0.6 ke atas dianggap tidak cocok.

        

        

          Apakah foto dikirim ke layanan pihak ketiga?
          
Tidak. API ini self-hosted: gambar hanya diproses di server Anda sendiri. Halaman demo ini pun
            mengirim gambar langsung ke URL endpoint yang Anda isi.

        

        

          Bagaimana cara menjalankannya?
          
Clone repo, lalu jalankan docker compose up -d --build. API tersedia di
            http://localhost:5000. Panduan lengkap ada di
            README.

        

        

          Apakah bisa dipakai untuk komersial?
          
Bisa. Proyek ini berlisensi MIT. Pastikan pemilik foto memberikan persetujuan dan Anda mematuhi
            regulasi perlindungan data pribadi yang berlaku (misalnya UU PDP).
